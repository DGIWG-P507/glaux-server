# Glaux Server

The foundational **gold standard** reference implementation of **OGC API - Connected Systems** for the DGIWG Glaux ecosystem.

## Mission

Glaux Server is the central authority node for secure sensor discovery, observation access, and tasking workflows in Joint ISR-aligned deployments.

## Conformance

Conformance is validated through an explicit **conformance test harness** and implementation profiles aligned to OGC and NATO interoperability requirements.
